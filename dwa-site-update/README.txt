【ファイルと置き場所】
 main/index.html      → メインサイト(地震速報LIVE)の index.html と差し替え

【今回の修正】
 1. 組織概要・沿革が開かない問題
    原因:メニューが、まだ公開されていない organization.html を開こうとしていたため。
    対応:メニューから、ポップアップで直接開くようにしました。新しいファイルを追加しなくても、
          index.html を差し替えるだけで開けます(メインサイト・長岡京市版の両方)。
          閉じるボタン、背景のタップ、Escキーで閉じます。
 2. 全ページが小さい問題(パソコン)
    画面の幅が1100px以上のときだけ、全体を拡大します(スマホ・タブレットは変更なし)。
      1100px以上 1.25倍 / 1500px以上 1.5倍 / 2000px以上 1.8倍 / 2800px以上 2.2倍
    対象:メインサイト、長岡京市版、活動と目標、スタッフ紹介・アクセス・問い合わせ、組織概要・沿革。
    拡大率を変えたい場合は、各ファイルの <style id="dwaPcScale"> の数字を変更してください
    (activity.html / staff.html / organization.html は、</style> の直前にあります)。
 3. メニューの整理
    「スタッフ紹介」「アクセス方法」「問い合わせ窓口」を、1つの項目
    「スタッフ紹介・アクセス・問い合わせ」(staff.html)にまとめました。
    staff.html の見出しと目次(スタッフ紹介/事務局/アクセス/問い合わせ窓口)も、これに合わせています。
